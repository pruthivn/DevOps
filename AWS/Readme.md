## 9. AWS Services Used

- DynamoDB provides state locking.

## 11. EC2 SSH Troubleshooting

- Verify NACLs
- Validate key pair
- Check SSH service
- Check disk usage

## 12. CloudWatch Alarms

- CPU utilization
- Memory utilization
- Disk usage
- Application health

## 13. Auto Scaling Group (ASG)

## 14. IAM User vs IAM Role
- User: Permanent credentials
- Role: Temporary credentials
